# Telegram Bot API Server

Веб-сервер на Flask и Telegram бот для управления клиентскими чатами через веб-интерфейс админки.

## 🚀 Основной функционал

- **Telegram бот** - принимает текстовые сообщения от клиентов с выбором статуса
- **REST API сервер** - предоставляет API для веб-админки
- **MongoDB** - надежное хранение всех данных
- **Статусы клиентов** - студент, абитуриент, родитель студента, родитель абитуриента
- **Статусы прочитанности** - отслеживание непрочитанных сообщений
- **Веб-интерфейс** - админка для переписки с клиентами

## 📋 Новые возможности v2.2

✅ **Настраиваемые сообщения** - редактируйте все тексты бота через API  
✅ **Динамические статусы** - добавляйте/удаляйте статусы без изменения кода  
✅ **Проверка студентов** - автоматическая валидация через внешний API  
✅ **Новый флоу регистрации** - выбор роли сразу при /start  
✅ **Статус прочитанности** - отслеживание непрочитанных сообщений  
✅ **Раздельный запуск** - Flask API и Telegram бот запускаются отдельно  
✅ **Безопасность** - секреты в .env файле

## 🛠 Установка

### 1. Клонирование и установка зависимостей

```bash
cd cpm-bot
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
# MongoDB Configuration
MONGO_HOST=109.73.202.73
MONGO_PORT=27017
MONGO_USERNAME=gen_user
MONGO_PASSWORD=your_password
MONGO_AUTH_DB=admin
MONGO_DATABASE=chatbot

# Telegram Bot Configuration
TELEGRAM_BOT_TOKEN=your_bot_token

# Flask Configuration
FLASK_HOST=0.0.0.0
FLASK_PORT=80
FLASK_DEBUG=True
```

**⚠️ ВАЖНО:** Никогда не коммитьте `.env` файл в git!

## 🚀 Запуск

Теперь Flask API и Telegram бот запускаются **отдельно**:

### Вариант 1: Использование скриптов (рекомендуется)

**Запуск API сервера:**

```bash
chmod +x start_api.sh
./start_api.sh
```

**Запуск Telegram бота (в другом терминале):**

```bash
chmod +x start_bot.sh
./start_bot.sh
```

### Вариант 2: Ручной запуск

**Терминал 1 - API сервер:**

```bash
source venv/bin/activate
python3 app.py
```

**Терминал 2 - Telegram бот:**

```bash
source venv/bin/activate
python3 bot.py
```

После запуска:

- 📡 API доступен: `http://0.0.0.0:80`
- 🤖 Бот готов принимать сообщения
- 📚 Документация: `http://0.0.0.0:80/api/docs`

**Для остановки:** Нажмите `Ctrl+C` в каждом терминале

## 📡 API Endpoints

### Чаты

- `GET /api/chats` - Список всех чатов
- `GET /api/chats/<chat_id>` - История чата
- `DELETE /api/chats/<chat_id>` - Удалить чат
- `POST /api/chats/<chat_id>/send` - Отправить сообщение
- `POST /api/chats/<chat_id>/mark-read` - Пометить как прочитанное

### Пользователи

- `GET /api/chats/<chat_id>/user` - Информация о пользователе
- `PUT /api/chats/<chat_id>/name` - Обновить имя
- `GET /api/chats/<chat_id>/status` - Получить статус
- `PUT /api/chats/<chat_id>/status` - Обновить статус

### Статусы (базовый API)

- `GET /api/statuses` - Список всех статусов (упрощенный)

### 🆕 Настройки бота (v2.2)

**Сообщения:**

- `GET /api/bot-messages` - Получить все сообщения
- `PUT /api/bot-messages` - Обновить все сообщения
- `GET /api/bot-messages/<key>` - Получить одно сообщение
- `PUT /api/bot-messages/<key>` - Обновить одно сообщение

**Статусы (расширенный API):**

- `GET /api/config/statuses` - Получить все статусы (с полной информацией)
- `POST /api/config/statuses` - Добавить новый статус
- `PUT /api/config/statuses/<value>` - Обновить статус
- `DELETE /api/config/statuses/<value>` - Удалить статус

### Рассылка

- `POST /api/broadcast` - Массовая рассылка по статусам

### Статистика

- `GET /api/stats` - Общая статистика
- `GET /api/health` - Проверка состояния

## 💬 Работа с ботом

### Регистрация (v2.2)

1. **Пользователь отправляет `/start`**
2. **Бот показывает inline кнопки с выбором роли**

**Для студентов/резерва (системные роли):** 3. При выборе "Студент" или "Резерв" → автоматическая проверка через API 4. Если найден в базе → ФИО берётся автоматически ✅ 5. Если не найден → предложение выбрать другую роль ❌

**Для остальных ролей:** 3. При выборе роли → просьба ввести своё имя 4. Пользователь вводит имя → регистрация завершена ✅

После регистрации пользователь может отправлять сообщения.

### Ограничения

- ✅ Принимаются только **текстовые сообщения**
- ❌ Фото, видео, голосовые, файлы - отклоняются
- 📩 Все сообщения сохраняются в БД
- 🔐 Студенты/резерв должны быть в базе учебного заведения

## 🔧 Примеры использования API

### Получение списка чатов

```bash
curl http://0.0.0.0:80/api/chats
```

### Отправка сообщения

```bash
curl -X POST http://0.0.0.0:80/api/chats/123456789/send \
  -H "Content-Type: application/json" \
  -d '{"message": "Привет!", "admin_name": "Менеджер"}'
```

### Пометить сообщения как прочитанные

```bash
curl -X POST http://0.0.0.0:80/api/chats/123456789/mark-read
```

### Обновить статус клиента

```bash
curl -X PUT http://0.0.0.0:80/api/chats/123456789/status \
  -H "Content-Type: application/json" \
  -d '{"status": "student"}'
```

### Получить статистику

```bash
curl http://0.0.0.0:80/api/stats
```
