# Новые функции v2.1

## 📋 Обзор изменений

Версия 2.1.0 добавляет три важные функции для улучшения работы с клиентами:

1. ✅ **Запрос имени при регистрации** - клиент представляется перед выбором статуса
2. ✅ **Редактирование имени через API** - возможность изменить имя из админки
3. ✅ **Удаление чатов** - полное удаление чата с пользователем и всех сообщений

---

## 🆕 1. Запрос имени при регистрации

### Изменения в боте

**Старый флоу:**

```
/start → Выбор статуса → Готово
```

**Новый флоу:**

```
/start → Ввод имени → Выбор статуса → Готово
```

### Как это работает:

1. **Пользователь пишет `/start`**

   ```
   Бот: Привет! 👋
        Я бот для связи с администратором.
        Как мне вас называть? Напишите ваше имя:
   ```

2. **Пользователь вводит имя** (например: "Иван Петров")

   ```
   Бот: Приятно познакомиться, Иван Петров! 😊
        Теперь выберите, кто вы:
        [👨‍🎓 Студент] [🎓 Абитуриент]
        [👨‍👦 Родитель студента] [👨‍👧 Родитель абитуриента]
   ```

3. **Пользователь выбирает статус**
   ```
   Бот: ✅ Отлично! Вы выбрали статус: Студент
        Теперь можете отправлять мне текстовые сообщения.
   ```

### Возвращающиеся пользователи:

При повторном `/start` пользователь с уже заполненными данными увидит:

```
Бот: С возвращением, Иван Петров! 👋
     Ваш статус: Студент
     Отправляйте мне текстовые сообщения.
```

### Технические детали:

**Изменения в `telegram_bot.py`:**

- Проверка наличия `name` и `status` в БД
- Обработка ввода имени в `handle_text_message()`
- Показ кнопок статуса после ввода имени

**Изменения в БД:**

- Поле `name` теперь содержит имя, введенное пользователем
- Старое поле `name` (из профиля Telegram) больше не используется для отображения

## 🔧 2. Редактирование имени через API

### Endpoint: `PUT /api/chats/<chat_id>/name`

Обновленный endpoint для изменения имени пользователя из админки.

### Запрос:

```bash
curl -X PUT http://0.0.0.0:80/api/chats/123456789/name \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Иван Петров (VIP)"
  }'
```

### Параметры:

| Параметр | Тип    | Обязательно | Описание                                      |
| -------- | ------ | ----------- | --------------------------------------------- |
| `name`   | string | ✅ Да       | Новое имя пользователя (не может быть пустым) |

### Ответы:

**✅ Успешно (200):**

```json
{
  "success": true,
  "message": "Имя пользователя обновлено успешно",
  "new_name": "Иван Петров (VIP)"
}
```

**❌ Пользователь не найден (404):**

```json
{
  "success": false,
  "error": "Пользователь не найден"
}
```

**❌ Пустое имя (400):**

```json
{
  "success": false,
  "error": "Имя не может быть пустым"
}
```

**❌ Поле отсутствует (400):**

```json
{
  "success": false,
  "error": "Поле 'name' обязательно"
}
```

### Улучшения:

- ✅ Проверка существования пользователя (404 вместо 500)
- ✅ Возврат нового имени в ответе
- ✅ Валидация на пустую строку
- ✅ Trim пробелов в начале и конце

### Пример использования в React:

```javascript
const updateUserName = async (chatId, newName) => {
  try {
    const response = await fetch(`/api/chats/${chatId}/name`, {
      method: "PUT",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ name: newName }),
    });

    const data = await response.json();

    if (data.success) {
      console.log("Имя обновлено:", data.new_name);
      return data.new_name;
    } else {
      throw new Error(data.error);
    }
  } catch (error) {
    console.error("Ошибка обновления имени:", error);
    throw error;
  }
};
```

## 🗑️ 3. Удаление чатов

### Endpoint: `DELETE /api/chats/<chat_id>`

Новый endpoint для полного удаления чата с пользователем.

### Что удаляется:

- ✅ Запись пользователя из коллекции `users`
- ✅ Все сообщения из коллекции `messages` для этого `chat_id`

### Запрос:

```bash
curl -X DELETE http://0.0.0.0:80/api/chats/123456789
```

### Параметры:

Параметров в теле запроса не требуется - только `chat_id` в URL.

### Ответы:

**✅ Успешно удалено (200):**

```json
{
  "success": true,
  "message": "Чат успешно удален",
  "deleted": {
    "user": true,
    "messages_count": 42
  }
}
```

**❌ Чат не найден (404):**

```json
{
  "success": false,
  "error": "Чат не найден"
}
```

**❌ Ошибка удаления (500):**

```json
{
  "success": false,
  "error": "Ошибка при удалении чата"
}
```

### Детали ответа:

| Поле                     | Тип     | Описание                       |
| ------------------------ | ------- | ------------------------------ |
| `deleted.user`           | boolean | Был ли удален пользователь     |
| `deleted.messages_count` | integer | Количество удаленных сообщений |

### ⚠️ Важно:

- Операция **необратима** - восстановить данные будет невозможно
- Рекомендуется добавить подтверждение в UI
- Если пользователь напишет боту снова, он создастся заново

### Пример использования в React:

```javascript
const deleteChat = async (chatId) => {
  // Подтверждение
  if (!confirm("Вы уверены? Это действие нельзя отменить!")) {
    return;
  }

  try {
    const response = await fetch(`/api/chats/${chatId}`, {
      method: "DELETE",
    });

    const data = await response.json();

    if (data.success) {
      console.log(
        `Удалено: пользователь + ${data.deleted.messages_count} сообщений`
      );
      // Обновить список чатов
      refreshChatList();
    } else {
      throw new Error(data.error);
    }
  } catch (error) {
    console.error("Ошибка удаления чата:", error);
    alert("Не удалось удалить чат");
  }
};
```

### Компонент с кнопкой удаления:

```jsx
function DeleteChatButton({ chatId, onDelete }) {
  const [isDeleting, setIsDeleting] = useState(false);

  const handleDelete = async () => {
    if (!confirm("Удалить этот чат? Все сообщения будут потеряны!")) {
      return;
    }

    setIsDeleting(true);

    try {
      const response = await fetch(`/api/chats/${chatId}`, {
        method: "DELETE",
      });

      const data = await response.json();

      if (data.success) {
        onDelete(chatId);
        alert(`Чат удален (${data.deleted.messages_count} сообщений)`);
      } else {
        alert("Ошибка: " + data.error);
      }
    } catch (error) {
      alert("Не удалось удалить чат");
    } finally {
      setIsDeleting(false);
    }
  };

  return (
    <button onClick={handleDelete} disabled={isDeleting} className="btn-danger">
      {isDeleting ? "Удаление..." : "🗑️ Удалить чат"}
    </button>
  );
}
```

## 📊 Изменения в базе данных

### Коллекция `users`

**Поле `name`:**

- **Раньше:** Автоматически из `first_name + last_name` профиля Telegram
- **Теперь:** Вводится пользователем при регистрации

### Требования к данным:

Для полноценной работы пользователь должен иметь:

- ✅ `chat_id` - уникальный ID чата
- ✅ `name` - введенное пользователем имя (обязательно)
- ✅ `status` - выбранный статус (обязательно)

## 🔄 Миграция существующих пользователей

### Для пользователей без `name`:

Если в БД есть старые пользователи без поля `name`, они получат такой опыт:

1. Пишут боту любое сообщение
2. Бот просит их ввести имя
3. После ввода имени - показывает кнопки статуса
4. После выбора статуса - могут общаться

### Скрипт миграции (опционально):

Если нужно автоматически установить `name` из старых данных:

```javascript
// В MongoDB shell
db.users.find({ name: { $exists: false } }).forEach(function (user) {
  const name = (user.first_name || "") + " " + (user.last_name || "");
  db.users.updateOne(
    { _id: user._id },
    { $set: { name: name.trim() || "Пользователь" } }
  );
});
```

## 🎯 Best Practices

### 1. Редактирование имени:

✅ **Правильно:**

- Показывать текущее имя в поле ввода
- Добавлять подтверждение изменений
- Обновлять UI после успешного изменения

❌ **Неправильно:**

- Менять имя без подтверждения
- Не проверять на пустую строку
- Не обрабатывать ошибки

### 2. Удаление чата:

✅ **Правильно:**

- Двойное подтверждение (модальное окно + кнопка)
- Показывать количество удаляемых сообщений
- Удалять из списка чатов после успешного удаления

❌ **Неправильно:**

- Удалять по одному клику
- Не показывать feedback
- Оставлять в UI после удаления

### 3. UI/UX рекомендации:

**Форма редактирования имени:**

```jsx
<Modal>
  <h3>Редактировать имя</h3>
  <input
    type="text"
    defaultValue={currentName}
    placeholder="Введите новое имя"
    required
  />
  <button onClick={handleSave}>Сохранить</button>
  <button onClick={handleCancel}>Отмена</button>
</Modal>
```

**Подтверждение удаления:**

```jsx
<Modal className="danger">
  <h3>⚠️ Удалить чат?</h3>
  <p>
    Будет удалено: - Пользователь: {userName}- Сообщений: {messageCount}
  </p>
  <p>
    <strong>Это действие необратимо!</strong>
  </p>
  <button className="btn-danger" onClick={handleDelete}>
    Да, удалить
  </button>
  <button onClick={handleCancel}>Отмена</button>
</Modal>
```
