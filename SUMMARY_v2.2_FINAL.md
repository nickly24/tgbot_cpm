## 📡 Новые API Endpoints

### Сообщения бота:

```
GET    /api/bot-messages           - получить все сообщения
PUT    /api/bot-messages           - обновить все сообщения
GET    /api/bot-messages/<key>     - получить одно сообщение
PUT    /api/bot-messages/<key>     - обновить одно сообщение
```

### Статусы клиентов:

```
GET    /api/config/statuses        - получить все статусы
POST   /api/config/statuses        - добавить статус
PUT    /api/config/statuses/<val>  - обновить статус
DELETE /api/config/statuses/<val>  - удалить статус
```

## 🎯 Новый флоу регистрации

### Системные роли (Студент/Резерв):

1. `/start` → Выбор роли
2. Нажал "Студент" → Проверка через API
3. Найден ✅ → ФИО автоматически + регистрация завершена
4. Не найден ❌ → Выбор другой роли

### Обычные роли:

1. `/start` → Выбор роли
2. Выбрал роль → Просьба ввести имя
3. Ввёл имя → Регистрация завершена

## 🚀 Как запустить

```bash

Если пусто - коллекция уже заполнена при запуске скрипта ранее.

```

## 🧪 Как протестировать

### Тест 1: Регистрация студента (успех)

1. Telegram: отправьте `/start` от пользователя с username в базе студентов
2. Нажмите "Студент"
3. Должно показать: "⏳ Проверяем данные..."
4. Затем: "✅ Добро пожаловать, ФИО!"
5. ✅ Регистрация завершена без ввода имени

### Тест 2: Регистрация студента (неудача)

1. Telegram: `/start` от пользователя БЕЗ username или не из базы
2. Нажмите "Студент"
3. Должно показать ошибку и предложить выбрать другую роль
4. ✅ Защита работает

### Тест 3: Регистрация обычной роли

1. Telegram: `/start`
2. Нажмите "Абитуриент"
3. Должно попросить ввести имя
4. Введите имя
5. ✅ Регистрация завершена

### Тест 4: Редактирование сообщения

```bash
curl -X PUT http://0.0.0.0:80/api/bot-messages/welcome \
  -H "Content-Type: application/json" \
  -d '{"text": "Новое приветствие!"}'
```

✅ Проверьте в боте - должно измениться

### Тест 5: Добавление статуса

```bash
curl -X POST http://0.0.0.0:80/api/config/statuses \
  -H "Content-Type: application/json" \
  -d '{"value":"vip","label":"VIP","emoji":"⭐"}'
```

✅ Проверьте - новая кнопка должна появиться в боте

## 🔗 Внешние зависимости

### API проверки студентов

- **URL:** `https://nickly24-cpm-serv-f15d.twc1.net/api/validate-student-by-tg`
- **Метод:** POST
- **Запрос:** `{"tg_name": "username"}`
- **Timeout:** 10 секунд

⚠️ **Важно:** Если этот API недоступен, студенты/резерв не смогут зарегистрироваться!

---

## ⚠️ Важные замечания

1. **Системные статусы защищены:**

   - `student` и `reserve` нельзя удалить
   - Можно изменить только label и emoji

2. **Username обязателен для студентов:**

   - Без @username нельзя зарегистрироваться как студент
   - Telegram должен быть настроен с username

3. **Обратная совместимость:**

   - Старые пользователи продолжат работать
   - Старый endpoint `/api/statuses` работает
   - Никаких breaking changes

4. **Изменения применяются мгновенно:**
   - Перезапуск не требуется
   - Бот читает из БД при каждом запросе
