### 📡 Новые API endpoints

- `POST /api/chats/<chat_id>/mark-read` - пометить сообщения как прочитанные
- `GET /api/statuses` - получить список всех статусов
- `GET /api/chats/<chat_id>/status` - получить статус пользователя
- `PUT /api/chats/<chat_id>/status` - обновить статус пользователя
- `GET /api/stats` - получить общую статистику

### 🔄 Обновленные endpoints

- `GET /api/chats` - теперь возвращает `unread_count` и `status`
- `GET /api/chats/<chat_id>` - добавлены поля `status`, `status_name`, `unread_count`
- `GET /api/chats/<chat_id>/user` - добавлено поле `status_name`

## Миграция с v1.x на v2.0

### 1. Очистка старой БД

```javascript
// В MongoDB shell
use chatbot
// Удалить все старые коллекции chat_*
db.getCollectionNames()
  .filter(name => name.startsWith('chat_'))
  .forEach(name => db[name].drop());
```

### 2. Создание .env файла

Создайте `.env` с секретами (см. QUICKSTART.md)

### 3. Обновление кода

```bash
git pull
source venv/bin/activate
pip install -r requirements.txt
```

### 4. Запуск

```bash
# Терминал 1
./start_api.sh

# Терминал 2
./start_bot.sh
```

### 5. Frontend обновления

- Обновите API клиент (см. REACT_EXAMPLES.md)
- Замените компоненты ThemeSelector на StatusSelector
- Добавьте компонент UnreadBadge
- Обновите хуки для работы с новыми полями
