## 👨‍🎓 СИСТЕМНЫЕ РОЛИ (Студент / Резерв)

**Роли:** `student`, `reserve`

**Особенность:** Автоматическая проверка и получение ФИО из внешней системы

### Шаги:

1. **Пользователь нажимает "Студент" или "Резерв"**
2. **Бот показывает:** `⏳ Проверяем данные...`

3. **Бот делает запрос на сервер:**

   ```
   POST https://nickly24-cpm-serv-f15d.twc1.net/api/validate-student-by-tg
   Body: { "tg_name": "@username" }
   ```

4. **Два варианта:**

   #### ✅ Студент найден:

   - Берём `full_name` из ответа сервера
   - Автоматически сохраняем имя и статус
   - Показываем:

     ```
     ✅ Добро пожаловать, Иванов Иван Иванович!

     Вы успешно зарегистрированы как: Студент

     Теперь можете отправлять мне текстовые сообщения...
     ```

   - **Регистрация завершена** ✅

   #### ❌ Студент НЕ найден:

   - Показываем:

     ```
     ❌ К сожалению, вы не найдены в базе студентов.

     Для регистрации как студент или резерв вы должны быть
     в базе учебного заведения.

     Если вы не студент, выберите другую роль:
     ```

   - Снова показываем кнопки выбора роли
   - Пользователь может выбрать другую роль

---

## 👨‍👦 НЕ СИСТЕМНЫЕ РОЛИ (Абитуриент, Родитель...)

**Роли:** все кроме `student` и `reserve`

**Особенность:** Пользователь сам вводит своё ФИО

### Шаги:

1. **Пользователь выбирает роль** (например, "Абитуриент")

2. **Бот показывает:**

   ```
   ✅ Вы выбрали статус: Абитуриент

   Теперь напишите ваше имя:
   ```

3. **Пользователь вводит своё имя**

   ```
   Пример: Петров Петр
   ```

4. **Бот подтверждает:**

   ```
   ✅ Отлично, Петров Петр!

   Вы успешно зарегистрированы как: Абитуриент

   Теперь можете отправлять мне текстовые сообщения...
   ```

5. **Регистрация завершена** ✅

## 🔧 Техническая реализация

### API проверки студента

**Endpoint:** `https://nickly24-cpm-serv-f15d.twc1.net/api/validate-student-by-tg`

**Метод:** `POST`

**Запрос:**

```json
{
  "tg_name": "username" // без @
}
```

**Ответ (успех):**

```json
{
  "status": true,
  "student_data": {
    "full_name": "Иванов Иван Иванович"
    // другие поля...
  }
}
```

**Ответ (не найден):**

```json
{
  "status": false
}
```

### Код проверки

```python
async def validate_student(self, username):
    """Проверка студента по username через внешний API"""
    if not username:
        return None

    try:
        url = "https://nickly24-cpm-serv-f15d.twc1.net/api/validate-student-by-tg"

        with httpx.Client(timeout=10.0) as client:
            response = client.post(url, json={"tg_name": username})
            response.raise_for_status()
            data = response.json()

            if data.get('status') and data.get('student_data'):
                return data['student_data']
            return None
    except Exception as e:
        logger.error(f"Ошибка проверки студента {username}: {e}")
        return None
```

## ⚠️ Важные моменты

1. **Telegram username обязателен** для студентов/резерва

   - Если у пользователя нет @username в Telegram, он не сможет зарегистрироваться как студент
   - В этом случае нужно выбрать другую роль

2. **Timeout API запроса:** 10 секунд

   - Если сервер не отвечает, пользователь увидит ошибку
   - Можно попробовать снова через /start

3. **Кэширование не используется**

   - Каждый раз при выборе роли делается свежий запрос к API
   - Это гарантирует актуальность данных

4. **Системные статусы защищены**
   - `student` и `reserve` нельзя удалить через API
   - Можно изменить только название и эмодзи
