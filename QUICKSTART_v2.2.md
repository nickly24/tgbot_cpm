# 🚀 Быстрый старт v2.2 - Настраиваемые сообщения и статусы

## ✨ Что нового в v2.2?

1. **Редактируемые сообщения бота** - изменяйте тексты через API
2. **Динамические статусы** - добавляйте/удаляйте статусы без изменения кода

---

## 🎯 Быстрый запуск

### 1. Запустите проект

```bash
# Терминал 1 - API
python3 app.py

# Терминал 2 - Бот
python3 bot.py
```

При первом запуске автоматически создастся коллекция `config` с дефолтными значениями.

### 2. Проверьте новые endpoints

```bash
# Получить все сообщения бота
curl http://0.0.0.0:80/api/bot-messages

# Получить все статусы
curl http://0.0.0.0:80/api/config/statuses
```

---

## 📝 Основные операции

### Редактирование сообщений бота

```bash
# Изменить приветственное сообщение
curl -X PUT http://0.0.0.0:80/api/bot-messages/welcome \
  -H "Content-Type: application/json" \
  -d '{"text": "Новое приветствие!"}'
```

### Управление статусами

```bash
# Добавить новый статус
curl -X POST http://0.0.0.0:80/api/config/statuses \
  -H "Content-Type: application/json" \
  -d '{"value": "vip", "label": "VIP Клиент", "emoji": "⭐"}'

# Обновить статус
curl -X PUT http://0.0.0.0:80/api/config/statuses/vip \
  -H "Content-Type: application/json" \
  -d '{"label": "VIP"}'

# Удалить статус (только не системные!)
curl -X DELETE http://0.0.0.0:80/api/config/statuses/vip
```

---

## 🎨 Доступные сообщения для редактирования

| Ключ                   | Описание                 | Плейсхолдеры              |
| ---------------------- | ------------------------ | ------------------------- |
| `welcome`              | Первое приветствие       | -                         |
| `ask_status`           | Просьба выбрать статус   | `{name}`                  |
| `status_selected`      | Подтверждение выбора     | `{status_name}`           |
| `welcome_back`         | Приветствие вернувшегося | `{name}`, `{status_name}` |
| `message_received`     | Подтверждение получения  | -                         |
| `unsupported_message`  | Ошибка типа сообщения    | -                         |
| `need_status`          | Напоминание о статусе    | -                         |
| `admin_message_prefix` | Префикс от админа        | `{admin_name}`            |

---

## 👥 Системные статусы

Два статуса **нельзя удалить**:

- `student` - Студент 👨‍🎓
- `reserve` - Резерв 📝

Для них можно изменить только `label` и `emoji`.
